# Black Friday Sales – Exploratory Data Analysis (EDA)

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** and **feature engineering** performed on the **Black Friday sales dataset**. The goal is to understand customer purchasing behavior, identify key factors influencing purchase amounts, and prepare the data for downstream machine learning models.

The analysis is implemented in a Jupyter Notebook and covers data cleaning, visualization, statistical insights, and feature transformations.

## 🗂 Dataset Description

The Black Friday dataset contains transactional data from a retail store, including customer demographics and product-related information.

### Key Columns

* **User_ID** – Unique customer identifier
* **Product_ID** – Unique product identifier
* **Gender** – Gender of the customer
* **Age** – Age group of the customer
* **Occupation** – Occupation code
* **City_Category** – Category of the city
* **Stay_In_Current_City_Years** – Years spent in the current city
* **Marital_Status** – Marital status indicator
* **Product_Category_1, 2, 3** – Product category codes
* **Purchase** – Purchase amount (target variable)

---

## 🔍 Analysis Performed

### 1. Data Cleaning

* Handling missing values in product categories
* Fixing data types and inconsistent values
* Removing or imputing null entries

### 2. Exploratory Data Analysis (EDA)

* Distribution analysis of purchase amounts
* Gender-wise and age-wise spending patterns
* Impact of city category and marital status on purchases
* Product category popularity analysis

### 3. Feature Engineering

* Encoding categorical variables
* Transforming ordinal features
* Preparing features for machine learning models
